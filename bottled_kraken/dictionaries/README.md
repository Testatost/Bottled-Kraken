Offline-Wörterbücher für Bottled Kraken. Benutzerwörter werden zur Laufzeit pro Sprache im lokalen Konfigurationsordner gespeichert und mit diesen eingebetteten Listen zusammengeführt.


Benutzerwörter werden nicht in diesen Programmdateien überschrieben, sondern lokal unter `~/BottledKraken/dictionaries/user/<sprache>.json` gespeichert. Im Optionen-Fenster wird der exakte Pfad für die aktuell gewählte Sprache angezeigt.
